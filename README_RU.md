## Python Shell by HayaraLV

![logo_image](images/image.png)

Кастомная легковесная командная оболочка, написанная на Python. Она воспроизводит основные функции Unix-терминала, включая встроенную навигацию, управление файлами, базовую работу с сетью и системные утилиты.

## Установка

Перед запуском оболочки убедитесь, что у вас установлен Python 3. Затем клонируйте репозиторий и установите необходимые внешние зависимости:

```bash
pip install -r requirements.txt
```

## Функционал

### Файловая система и навигация
* **cd** — Смена текущей рабочей директории.
* **ls** — Просмотр содержимого директории.
* **tree** — Отображение структуры директории в виде визуального дерева.
* **mkdir** — Создание новой директории.

### Управление файлами и текстом
* **touch** — Создание нового пустого файла.
* **cat** — Чтение и вывод содержимого файла на экран.
* **edit** — Встроенный в терминал текстовый редактор для изменения файлов.
* **echo** — Вывод текста или перенаправление вывода в файл.
* **note** — Инструмент для быстрого создания заметок с поддержкой аргументов.
* **cp** — Копирование файла или директории.
* **mv** — Перемещение или переименование файла или директории.
* **rm** — Удаление файла или директории.
* **grep** — Поиск текстового паттерна внутри файлов.

### Сеть и запуск
* **wifi** — Управление Wi-Fi соединениями (просмотр, подключение, отключение).
* **curl** — Скачивание файлов из интернета по URL.
* **ping** — Проверка доступности хоста и статуса URL.
* **run** — Запуск внешних файлов, скриптов и системных команд.

### Система и окружение
* **sys** — Отображение краткой технической информации о системе.
* **neofetch** — Визуальный детализированный вывод информации о системе.
* **date** — Вывод текущей даты и времени.
* **clear** — Очистка экрана терминала.

### Управление терминалом
* **help** — Просмотр списка доступных команд и инструкций по их использованию.
* **history** — Просмотр и очистка истории выполненных команд.
* **exit** — Завершение работы системы или безопасное закрытие сессии терминала.

### Архитектура
* **Кастомный парсер команд** — Собственная логика для надежной обработки команд и аргументов.
* **Кроссплатформенность** — Полностью написано на Python для обеспечения совместимости с Windows, macOS и Linux.

## Инструкция по запуску

Программу можно запустить на Linux, Windows и macOS. В зависимости от операционной системы используйте соответствующие команды ниже.

### Linux
Для корректной работы скрипта в Linux требуются права суперпользователя (`sudo`):
```bash
sudo /usr/bin/python3 /PythonShell/PS/PyShell.py
```
Альтернативный вариант — перейти в директорию проекта и запустить:
```bash
cd PythonShell/PS/
sudo python3 PyShell.py
```

### Windows
В среде Windows используйте стандартный интерпретатор `python` (или лончер `py`) и обратные слэши `\` в путях.

**Обычный запуск:**
```cmd
python "C:\PythonShell\PS\PyShell.py"
```

**С правами администратора:**
1. Откройте **Командную строку** или **PowerShell** от имени администратора.
2. Выполните следующие команды:
```cmd
cd "C:\PythonShell\PS"
python PyShell.py
```

### macOS
macOS использует Unix-структуру путей, где домашняя директория пользователя находится в каталоге `/Users/`.

```bash
sudo python3 /PythonShell/PS/PyShell.py
```
Альтернативный вариант — перейти в директорию проекта и запустить:
```bash
cd /PythonShell/PS
sudo python3 PyShell.py
```
